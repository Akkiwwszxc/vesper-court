# Веспер Корт

Интерактивная 3D-модель жилого дома: пять этажей, 20 квартир. Дом можно вращать, любой этаж открывается по клику как макет архитектора, у каждой квартиры есть планировка, площадь, цена и статус. Работает в браузере на Three.js, сборка не нужна.

Проект выдуманный: название, адрес, цены и контакты ненастоящие.

## Живая версия

Включите GitHub Pages: **Settings → Pages → Branch: `main`, папка `/ (root)` → Save**. Через минуту страница откроется по адресу `https://<ваш-логин>.github.io/vesper-court/`.

## Запуск у себя

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Через сервер, а не двойным кликом: странице нужно читать `photos/manifest.json`.

## Что внутри

| Путь | Что это |
| --- | --- |
| `index.html` | вся страница: разметка, стили и код сцены |
| `vendor/three.min.js` | Three.js r128 (лицензия MIT) |
| `shots/` | 20 снимков квартир из 3D для Higgsfield |
| `photos/` | сюда кладут готовые фотографии |
| `tools/make_shots.py` | перегенерирует снимки |

## Управление

- Мышь: тянуть для вращения, колесо приближает, клик по этажу открывает его.
- Телефон: тянуть, сводить пальцы, тап по этажу.
- Слева кнопки этажей, «Все» возвращает дом целиком. Стрелки вверх и вниз листают этажи.
- Сверху виды «Квартиры», «Крыша», «Улица». В карточке этажа переключатель м² и фут².

## Что менять

Всё в начале скрипта в `index.html`:

- `FLOORS` — число этажей. Квартир на этаже четыре.
- `ppsm` — цена за квадратный метр, `pS` — доля проданных квартир по этажам.
- Контакты и адрес — в разметке окна «Офис продаж».

## Фото квартир через Higgsfield

Так сделан оригинальный рилс: комнаты снимают в 3D, а потом нейросеть делает из снимков фотографии.

1. **Снимки.** В `shots/` лежат кадры `f{этаж}-{номер}.jpg`, номер от 0 до 3 (квартиры А, Б, В, Г). Тот же кадр открывается на странице по адресу `#shot-5-1` (пятый этаж, вторая квартира).
2. **Генерация.** В Higgsfield выберите Nano Banana или Seedream, режим «картинка по картинке», загрузите снимок и вставьте промпт:

   > Photorealistic interior photograph of a furnished apartment, based on this 3D cutaway render. Keep the exact layout, wall positions, bed, sofa and kitchen placement and the camera angle. Warm evening light, oak floor, white plaster walls, linen textiles, soft shadows, 35mm lens, high detail, no people, no text.

3. **Подключение к странице.** Положите результаты в `photos/` и опишите их в `photos/manifest.json`. Ключ — номер квартиры или `type-1` и `type-2` (по числу спален) для общих фото:

   ```json
   {
     "3Б": ["photos/3b-living.jpg", "photos/3b-bedroom.jpg"],
     "type-2": ["photos/two-bed-living.jpg"]
   }
   ```

   Фото появятся в карточке квартиры.

### Подключить Higgsfield к Claude

У Higgsfield есть MCP-сервер: `https://mcp.higgsfield.ai/mcp`, ключ API не нужен. В настройках Claude добавьте его как пользовательский коннектор и войдите в свой аккаунт Higgsfield. Тогда Claude сможет сам отправлять снимки из `shots/` на генерацию и класть результат в `photos/`. Подробности на странице [higgsfield.ai/mcp](https://higgsfield.ai/mcp).
